
To-Do List Web App

Web Development Internship – Task 2

Project Description

This project is a simple and interactive To-Do List Web Application developed using HTML, CSS, and Vanilla JavaScript.

Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- User-friendly interface.
- Instant updates without page reload.

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Structure

Task-2-Todo-List/
│
├── index.html
├── style.css
├── script.js
└── README.md

How to Run

1. Download or clone the repository.
2. Open the folder in VS Code.
3. Open "index.html" using Live Server.
4. Start adding and managing tasks.

Learning Outcomes

- DOM Manipulation
- Event Listeners
- JavaScript Functions
- Dynamic UI Updates
